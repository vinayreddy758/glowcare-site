# GlowCare — Skincare Clinic Website

GlowCare is a web development project designed for a skincare clinic, providing visitors with a clean, user-friendly online experience and an administration panel.

## Features

- Responsive website interface
- Skincare clinic information and service presentation
- Admin panel for authorized management and booking system 
- Authentication powered by the configured backend

## Tech Stack

- **Frontend:** React, TypeScript
- **Framework:** TanStack Start
- **Styling:** Tailwind CSS
- **Backend Integration:** Supabase

## Getting Started

### Prerequisites

- Node.js and npm
- Required environment variables

### Installation

Clone the repository:

```bash
git clone https://github.com/vinayreddy758/glowcare-site.git
cd glowcare-site
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables in a local `.env` file.

Start the development server:

```bash
npm run dev
```
